# Lapsa Landing Page

Production-quality landing page for **Lapsa** — an AI Telegram bot that acts as a senior media buyer for ecommerce store owners.

## What is Lapsa?

Lapsa connects Shopify + Google Ads + GA4, sends a daily brief at 8 AM, and lets store owners ask questions in plain language via Telegram — like texting a senior media buyer who actually reads your data.

## Setup

### Prerequisites
- Node.js 18+
- Python 3.11+
- `uv` at `~/.local/bin/uv`

### Frontend

```bash
cd frontend
npm install
npm run dev
# → http://localhost:3000
```

If the frontend should proxy waitlist submissions to a non-local backend, set:

```bash
API_BASE_URL=https://your-api.example.com npm run dev
```

### Backend (separate terminal)

```bash
cd backend
~/.local/bin/uv sync
~/.local/bin/uv run uvicorn main:app --reload --port 8000
# → http://localhost:8000
```

The SQLite database (`backend/lapsa.db`) is created automatically on first startup.

### Build check

```bash
cd frontend
npm run lint
npm run build
```

## API

### `POST /waitlist`
```json
{ "email": "user@example.com" }
```
Returns: `{ "success": true, "message": "You're on the list! We'll be in touch." }`

Rate limited: 5 requests/minute per IP.

### `GET /health`
Returns: `{ "status": "ok" }`

## SEO & CRO notes

- **JSON-LD structured data**: `SoftwareApplication` schema with offers and aggregate rating
- **Open Graph + Twitter Card**: full metadata in `layout.tsx`
- **Canonical URL**: set to `https://lapsa.lv`
- **Security headers**: X-Frame-Options, CSP, Referrer-Policy, Permissions-Policy
- **Sitemap + robots.txt**: auto-generated by Next.js App Router
- **Conversion flow**: Hero CTA → Pricing → CTA Section (email capture)
- **Trust signals**: read-only badge, testimonials, stats, GDPR mention
- **Mobile nav**: full-screen hamburger menu on mobile
